# Kaynak medya

Masaüstündeki `adıyörem` klasörünün içeriği buraya konur. Dosya adları serbesttir. Türkçe karakter ve boşluk da olabilir.

- **Logo:** `logo.png` (tercihen saydam zemin).
- **Fotoğraflar:** JPG, PNG, HEIC ya da WEBP. Telefonla çekilmiş olabilir, yön kendiliğinden düzeltilir.
- **Videolar:** MP4 ya da MOV. Dikey çekim en iyisidir. 10 saniyeden kısa, en iyi anları içeren klipler yeterlidir.
- **Şube bilgisi:** Bir `bilgi.txt` içine şube adı, adres, telefon, varsa çalışma saatleri ve sipariş kanalları yazılabilir.

GitHub'ın web arayüzünde dosya başına sınır 25 MB'tır. Daha büyük videolar kısaltılarak ya da GitHub Desktop ile
yüklenebilir (dosya başına 100 MB).
